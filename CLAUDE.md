# Репозиторий видеомонтажа

Здесь монтируются ролики кодом через `vedit` (Python + ffmpeg + Node). Для любой задачи с видео
используй скилл `.claude/skills/video-edit/SKILL.md` — там весь процесс: анализ → план (edit.json) → рендер → проверка.

- Исходники: `input/` (большие файлы — через Git LFS), результаты: `output/`, временное: `work/` (не коммитится).
- Установка зависимостей: `bash scripts/setup.sh` (запускается автоматически хуком SessionStart).
- Пример плана со всеми возможностями: `examples/edit.example.json`.
